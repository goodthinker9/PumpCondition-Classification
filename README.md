# Pump Condition Classification Using Machine Learning

## Project Description

This project focuses on developing a Machine Learning system to classify the operating condition of an industrial pump using sensor data.

The system analyzes important pump measurements, including:

- **Vibration:** Measures the pump's vibration level (mm/s).
- **RPM:** Measures the pump's rotational speed.
- **Temperature:** Measures the pump's operating temperature (°C).
- **Pressure:** Measures the pump's pressure.
- **Operating Hours:** Records how long the pump has been operating.

Based on these input features, the system aims to classify the pump condition into three categories:

1. **Normal** – The pump is operating under normal conditions.
2. **Warning** – The pump may have an abnormal condition that needs attention.
3. **Fault** – The pump shows signs of a possible failure and requires inspection.

## Project Objectives

- Analyze pump sensor data.
- Prepare and preprocess the dataset.
- Apply different Machine Learning classification algorithms.
- Train and test the models.
- Compare model performance using evaluation metrics.
- Identify the model that performs best, especially in detecting pump faults.

## Machine Learning Algorithms

The project explores the following algorithms:

- Support Vector Machine (SVM)
- Gaussian Naive Bayes
- Decision Tree
- Random Forest
- AdaBoost

## Model Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Special attention is given to **Fault Recall and Fault Precision** because correctly identifying possible pump failures is important.

## Expected Outcome

The expected outcome is a trained classification model that can analyze pump sensor measurements and predict whether a pump is operating normally, needs attention, or may have a fault.

**Note:** This project is an academic machine learning exercise. Predictions are intended to support engineering inspection and do not replace professional maintenance decisions or safety procedures.
